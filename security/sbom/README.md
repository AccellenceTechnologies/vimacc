# Software Bill of Materials (SBOM)

This directory contains Software Bills of Materials (SBOMs)
for vimacc release artifacts and runtime environments.

SBOMs are published in CycloneDX JSON format and may include
additional metadata based on:

- Accellence CycloneDX Property Taxonomy
- BSI TR-03183 CycloneDX Property Taxonomy

The SBOMs are intended to support software supply chain
transparency, vulnerability management and compliance processes.
