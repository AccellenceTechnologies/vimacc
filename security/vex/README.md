# Vulnerability Exploitability eXchange (VEX)

This directory contains VEX documents related to
published vulnerabilities and vimacc products.

VEX documents are used to communicate whether specific
vulnerabilities affect vimacc components or deployments,
including contextual product impact assessments.

The documents may reference:

- CycloneDX VEX
- CSAF VEX profiles
- Product-specific vulnerability evaluations
